# Completion and verification boundaries

The core demonstration is a Python 3.9+ standard-library pipeline that generates isolated v2 logs, checks tri-state rules, derives summaries, and packages a static dashboard with source downloads and SHA-256 hashes. Optional field results remain historical observational proxies. Required CSVs missing or inconsistent fail visibly; the optional field summary is explicitly unavailable. Canonical historical inputs and the v1 checker are retained.

Run `./scripts/verify.sh` for the full suite. The portable HTTP test serves the actual bundle where loopback is permitted and skips that network assertion with an explicit reason in a restricted sandbox. Desktop/mobile browser inspection is recorded separately by the delivery reviewer; this document does not claim a screenshot or browser result.

No live Odoo session ran in this delivery: daemon availability and an isolated runtime blocked it. An auditable export and observed controls remain prerequisites to a transfer claim. The example ERP CSV is synthetic. The raw XES is not bundled; its exact redistribution license is unverified. The original user's files were preserved through an isolated checkout, and no push or deployment is part of this delivery. Historical promotional video was not updated.
