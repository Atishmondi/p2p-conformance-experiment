## Delivered

- `src/validate_erp_export.py`: `validate_export(path: Path) -> list[dict[str,str]]`, `write_export(rows, path) -> None`, and `python3 src/validate_erp_export.py INPUT --out CSV`. Requires named recorded action, nonblank unique `event_id` and `(source_model,source_id)`, timezone-aware recorded ISO timestamp, same `(product_id,uom)` in each case, exact within-case `invoice_event_id` on payment, and event-delta received/invoiced quantity at only the corresponding action. Unknown/unsupported activities, duplicate actions, extra CSV fields, reversals, date-only/naive/occurred timestamps, empty export, missing quantity and unmapped payments raise `ValueError`. Validates before touching output; writes deterministic case/time/event-ID sorted, UTC-normalized CSV through an atomic replacement. Does **not** prove source authenticity, actor truth or financial reconciliation. R5 remains temporal precedence only.
